About This Project

Sources & Method

This site converts a set of supplied revision-sheet infographics — covering the Prehistoric Age through the Khalji Dynasty (1206–1320 CE) within the Delhi Sultanate — into an interactive, interconnected reference. The chronology, terminology, dates, phases and level of detail follow the source sheets; nothing has been invented to make a period look fuller than its source material supports.

What comes from the source sheets

Every period overview, phase, event, aspect-wise table, list of women's contributions, list of important sites, and UPSC Prelims/Mains point on this site is drawn from the corresponding revision sheet, which you can open at any time via the "View Original Revision Sheet" control on each period page.

What is added for navigation only

Search indexing, cross-linking between periods/people/themes, and the small set of curated external reference links (Britannica, UNESCO, Government portals) are added purely as navigation aids and are visually distinguished with an example ↗ external-link style. They are not part of the original source material.

Coverage

The current build covers 14 periods across Ancient, Early Medieval and Sultanate India. The data architecture (data/history.json) is designed so that later periods — the Mughal Empire, British Colonial Rule, and Independent India — can be added by extending the JSON file and dropping in the corresponding infographic, without any redesign. See the README in the project repository for the exact steps.
